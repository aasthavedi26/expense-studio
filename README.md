# Expense Studio

Expense Studio is a modern AI-powered personal expense management dashboard designed to help users track spending, manage budgets, plan recurring expenses, and monitor financial goals.

## Features

- Expense and income tracking
- Budget management
- Recurring transactions
- Financial goals
- Interactive dashboard
- Spending insights
- Category-based expense analysis
- Responsive design
- Modern fintech-style UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Chart.js

## Getting Started

Install dependencies:

npm install

Start the application:

npm start

Open:

http://localhost:3000
